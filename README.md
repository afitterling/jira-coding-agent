# jira-coding-agent

An agent that pulls stories from a Jira Kanban board and revises, then implements them
via label-driven prompts (`#revise`/`#undone` → `#revised`, `#ready` → `#implemented`).

See [`docs/system-flow.mmd`](docs/system-flow.mmd) / [`docs/system-flow.svg`](docs/system-flow.svg) for the system flow.
